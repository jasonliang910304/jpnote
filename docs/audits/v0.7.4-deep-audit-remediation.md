## v0.7.4 implemented scope

### 1. Restore / undo compatibility gate — High

`restore_database_from()` 不再只依 SQLite `quick_check` 決定是否可 replace 正式 DB。

新的 gate：

1. source 必須具有可辨識的 legacy jpnote core tables/columns；
2. future schema version fail closed；invalid schema version fail closed；
3. 將 candidate copy 到 private/in-memory snapshot，只在 snapshot 執行 `migrate_schema()`；
4. migration 後確認 current schema version、required tables 與所有 repository-consumed columns 可讀；
5. `quick_check` 與 declared `foreign_key_check` 必須通過；
6. `command_undo` 在建立 recovery-before-undo 前先做 side-effect-free precheck；
7. `restore_database_from()` 對即將 replace 正式 DB 的 exact private copy 再做一次 gate，避免 backup path 在 CLI precheck 後被替換。

Compatibility 刻意以「目前 app 的 migration path 能否成功使用」定義，而不是強迫歷史 DB 事先具備今天所有 UNIQUE/FK declaration；這避免 safety gate 反過來破壞既有 legacy migration compatibility。

### 2. Public `JpnoteCore` true read-only

list/search/browse/recent/get/romaji-audit/mistakes/attempts/get-attempt/audit/duplicates/stats 全部由 writable `connect()` 改為 `connect_readonly()`。prepare/preflight/resolve import 仍走 isolated `connect_preflight()`；mutation methods 仍走 shared safe mutation boundary。

Quiz `StudySourceService.from_default_core()` 透過 `JpnoteCore` 讀 core，因此 default Quiz source catalog 也不再因 read 建 data dir、migrate 正式 DB、recover pending backup、prune 或 chmod。

### 3. Post-commit Markdown export semantics

新增 `PostCommitExportError`：SQLite mutation commit 已成功，但 derived Markdown refresh 失敗時，不再以普通 I/O error 讓 caller 誤判 DB rollback。

- pre-mutation undo snapshot 仍發布；
- Ctrl-C/`KeyboardInterrupt` 發生於 post-commit export 時也保留 snapshot；
- protocol error type 為 `post_commit_export_error`，additive 回傳 `database_committed=true`、`modified=true`、`export_status=failed` 與 backup path；
- import source cleanup 不會在 exception path 執行；
- undo 已 restore 成功但 Markdown refresh 失敗時，也使用同一語意回報 restore 已發生。

### 4. Attempt same-event canonical content semantics

`linked_entries` 在 public import normalization 視為 set-like relation，排序去重；batch same-event comparison 共用 `attempt_content_signature()`。因此 `[A,B]` / `[B,A]` 不再在 normalization 報 conflict，而不同 link set 仍 fail closed。

### 5. Directed relation reciprocal audit

reciprocal/inverse pair marker 改為一對 directed logical identity，而不是分別 sort source/target 與 relation types。已知 counterexample：

```text
A → B 前置文法
B → A 延伸
B → A 前置文法
```

現在 audit 會正確回報缺少 `A → B 延伸`，repair 後再 audit 為 clean。

### 6. Deterministic duplicate remap

多個 incoming keys 映射到同一 target 時，先以 deterministic source-key ordering 合併 collection fields，再明確決定 scalar precedence：

- incoming item 本身就是 target key：explicit target scalar 優先；
- mapped sources 單一/一致 value：保留既有 single-source remap 可更新 canonical display 的行為；
- 多來源 scalar 衝突且 existing target 有值：existing target 為 canonical；
- 多來源衝突且 target 無值：fail closed，要求人工決定。

舊 display 及 mapped variant display 以 deterministic alias enrichment 保留。

### 7. Legacy paste bounded UTF-8 transport

`jpnote paste --stdin` 改用既有 bounded `read_import_stdin()`；Wayland clipboard 改以 bounded byte stream 讀 `wl-paste`，最多讀 `MAX_IMPORT_BYTES + 1`，超限立即 kill child。兩者共用 strict UTF-8/BOM-aware decoder，與正式 `import --stdin` 一致為 16 MiB 上限。

`parse_payload()` repeated `raw_decode` 的超線性演算法 finding 未在此版重構，排入 v0.7.5；v0.7.4 先用 ingress hard cap 限制 blast radius。
