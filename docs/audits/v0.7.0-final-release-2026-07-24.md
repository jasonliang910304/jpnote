## Launcher isolation finding and fix

The v0.6.6.4 launcher used `PYTHONPATH` with `python3 -m jpnote_app`, allowing a
same-named package in the caller's current directory to shadow the installed
version. The v0.7.0 launcher uses `python3 -I`, an explicit versioned
`JPNOTE_APP_DIR`, and `runpy`.

Validated behavior:

```text
outside repository: jpnote 0.7.0
inside repository:  jpnote 0.7.0
PYTHONPATH shadow:   blocked
```
