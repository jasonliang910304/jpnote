# v0.7.0 Launcher Path Isolation — Development Checkpoint

Date: 2026-07-24

## Finding

The generated launcher used `PYTHONPATH` together with
`python3 -m jpnote_app`. A `jpnote_app` package in the caller's current
directory could therefore shadow the versioned installed package.

This was observed directly:

```text
outside the repository: jpnote 0.6.6.4
inside the repository:  jpnote 0.7.0
```

The installed launcher still pointed to v0.6.6.4; only module resolution had
changed.

## Fix

The generated launcher now:

- exports the explicit versioned `JPNOTE_APP_DIR`;
- starts Python in isolated mode with `python3 -I`;
- inserts only the installed application directory before running
  `jpnote_app` through `runpy`;
- ignores current-directory and `PYTHONPATH` package shadows;
- preserves command arguments and the caller's working directory.

## Regression coverage

`tests/test_launcher_path_isolation.py` verifies both current-directory and
`PYTHONPATH` shadow attempts, checks the installed version, and inspects the
generated launcher bootstrap.

## Data safety

The tests install only into a temporary `HOME`. They do not open or modify the
normal core or Quiz databases.

Normal imports remain paused until the fixed production snapshot, upgrade
smoke, and real installed-launcher validation are complete.
