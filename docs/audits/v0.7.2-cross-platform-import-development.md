## Scope

- `jpnote import --stdin`／`jpnote import -`
- versioned `jpnote.import.v1` JSON protocol

本版不修改 core SQLite schema v5、Quiz schema v2 或 public import JSON schema。

## Threat／failure preflight

### Transport and parser

- locale-dependent decoding：core 直接讀 stdin bytes，以 strict `utf-8-sig` 解碼。
- unbounded stdin／file allocation：core 與 Windows client 都限制 16 MiB。
- mixed human/machine output：protocol success/error 只在 stdout 回傳單一 ASCII-safe JSON envelope；human warnings 留在 stderr。
- protocol drift：client 驗證 protocol id/version/mode/ok，無法解析或輸出不明時 fail closed。

### Stale approval and concurrent writers

- Windows precheck 使用與 apply 相同的 `--yes` safe-fix 模擬。
- check 對 normalized plan＋preflight report 產生 SHA-256 `preflight_token`。
- apply 帶回 token；payload、resolution 或相關 DB outcome 改變時立即拒絕。
- token 通過後，v0.7.1 writer lock 內仍會重新建立 DB-dependent warnings/preflight；兩層檢查皆不可省略。

### Windows local file

- strict UTF-8／JSON syntax validation。
- 拒絕 directory 與 reparse point。
- snapshot 讀取期間比對 size、creation time、last-write time。
- 正式 apply 前再次比對 SHA-256；成功後刪除前再比一次。
- remote import 未明確成功、token 不一致、review/conflict、source drift 或 delete error 都不刪 Windows source。
- source cleanup 是 post-commit fail-soft；刪檔失敗不回滾已成功 DB transaction。

### SSH and command construction

- host／alias 僅接受安全字元；其他 remote arguments 固定，token 僅接受 64 位 lowercase hex。
- 原始 JSON bytes 寫入 `ssh.exe` stdin，不使用 PowerShell text pipeline、clipboard、Base64、shell interpolation 或 remote temp file。
- stderr 不 redirect，讓 OpenSSH passphrase prompt 保持連到 Windows console；此行為已由 Windows PowerShell 5.1＋真實 SSH 實機確認。

### Windows installation

- PowerShell module 使用 versioned directory 與 manifest。
- installer 預設同時安裝 Windows PowerShell 5.1／PowerShell 7 user module path。
- same-version reinstall 先移至 `_backups`；新安裝驗證失敗時回復舊 target。
- existing reparse-point install target／legacy file fail closed。
- uninstall 只移除精確 0.7.2 target，拒絕 reparse point，不碰 backup 或其他版本。
